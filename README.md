# Mini Racing

A lightweight 2D racing game for iPhone.

## Features

- Landscape gameplay
- SpriteKit 2D graphics
- Offline racing mode
- Local Wi-Fi multiplayer foundation
- Multiplayer discovery with MultipeerConnectivity
- Adaptive screen layout
- iOS 12.0 minimum deployment target

## Requirements

- Xcode
- XcodeGen
- iOS 12.0 or newer

## Generate Xcode project

```bash
brew install xcodegen
xcodegen generate
